# 成本核算

在 Token 统计之外追踪每次请求的花费，回答「这个月用了多少钱」。

## 计价方式（双通道）

| 通道 | 优先级 | 说明 |
|------|--------|------|
| 上游实时计价 | **优先采信** | 部分上游（如 OpenRouter）在响应的 usage 中直接返回本次成本，系统原样记录 |
| 价格表估算 | 回退 | 上游未自报成本时，按「模型价格表」中的单价乘以实际 token 数计算 |

两个通道都拿不到数据时该次请求成本记 0——**不会猜测默认价**，缺价模型请在价格表中补录。

## 维护价格表

管理后台「系统设置 → 模型价格表」：

- 单价为**美元 / 百万 token**，分输入价与输出价
- 「从 LiteLLM 导入」一键拉取社区维护的全量价格表并合并（同名模型以导入值覆盖），适合首次初始化
- 手动添加/修改/删除任意条目；保存时逐条校验，非法数据整体拒绝

## 在哪看费用

| 位置 | 内容 |
|------|------|
| 仪表盘 | 累计成本卡片 |
| 用量统计 | 趋势区窗口费用合计、按 Key / 按平台的费用列 |
| 请求日志 | 明细与归档列表的费用列 |

归档后费用随每日统计持久保存，不会因明细日志过期而丢失历史总额。

::: tip 免责声明
费用由上游实时计价或价格表估算得出，**仅供参考，实际以服务提供商为准**。所有费用展示处均有相同提示。
:::
