# 功能特性

## 多平台统一接入

统一 API 入口访问主流 AI 平台（OpenAI 兼容接口直接接入，Anthropic 原生协议自动转换）：

- **OpenAI** — GPT-4o、GPT-4、GPT-3.5
- **Anthropic** — Claude 3.5、Claude 3
- **Google** — Gemini 1.5、Gemini Pro
- **其他** — 任何 OpenAI 兼容的 API

## 智能路由

- **优先级路由**：数值越大优先级越高
- **权重路由**：按权重比例分配请求
- **故障转移**：平台故障自动切换到其他平台
- **熔断保护**：连续失败后暂停请求，避免雪崩
- **半开探测**：冷却期后自动探测恢复

## 用量监控

- **实时仪表盘**：请求数、Token 用量、TTFT 延迟
- **趋势图表**：小时/天级别趋势，支持单日小时级展示
- **平台对比**：各平台的请求分布和性能对比
- **日志归档**：30 天前的详细日志自动聚合为统计数据

## 成本核算

- **双通道计价**：上游自报成本优先采信，价格表估算兜底
- **价格表管理**：美元/百万 token 单价维护，一键导入 LiteLLM 社区价格表
- **费用报表**：仪表盘累计成本、按 Key/平台的费用列、日志级费用明细
- 详见[成本核算](/guide/cost)

## 告警通知

- **Webhook 推送**：Key 封禁、平台熔断/降级、全平台不可用、配额达 80% 五类事件
- **多通道并发**：兼容 Telegram Bot / Bark / Server酱 等常见推送服务
- **防轰炸**：同类事件冷却窗口去重；通知发送完全旁路，不影响请求
- 详见[告警通知](/guide/notifications)

## API Key 管理

- **多级配额**：Token 额度、调用次数、RPM/TPM 限制
- **自动重置**：按月/按天/永不重置
- **过期管理**：设置过期时间，自动禁用
- **用量预警**：配额用到 80% 时推送提醒

## 出站代理

- **订阅拉取**：从订阅链接批量拉取代理列表，按组管理与定时同步
- **健康检查**：定时探测代理可用性，自动标记不可用节点
- **细粒度绑定**：平台级与 API Key 级的代理组路由
- **多协议**：HTTP / SOCKS4 / SOCKS5
- 详见[出站代理](/guide/upstream-proxy)

## 安全特性

- **JWT 认证**：管理员登录保护，可选 TOTP 两步验证（验证器 App 动态码）
- **速率限制**：平台级和 Key 级 RPM/TPM 限制
- **安全头**：CSP、HSTS、X-Frame-Options 等
- **爬虫拦截**：阻止搜索引擎和 AI 爬虫索引

## 数据管理

- **数据导出**：系统配置和业务数据完整导出
- **数据导入**：支持迁移和备份恢复
- **定时备份**：每日自动将配置快照 AES-GCM 加密后推送到你指定的接收端
- **审计日志**：记录所有管理员操作

## 开发调试

- **Playground 调试台**：后台直接向任意模型发真实请求，走完整代理链路
