# 模型映射

## 什么是模型映射

模型映射允许你将一个模型名映射到另一个模型名。例如：

- 客户端请求 `gpt-4` → 实际调用 `gpt-4o`
- 客户端请求 `claude-3` → 实际调用 `claude-3-5-sonnet`

## 配置模型映射

当前版本模型映射**没有独立的管理页面**，通过「数据管理」页面的**导出/导入**功能维护：

1. 在管理后台「数据管理」页面点击「导出」，选择**系统配置**，得到包含 `modelMaps` 的 JSON 文件
2. 在 JSON 的 `modelMaps` 数组中添加或修改映射记录：

```json
{
  "alias": "gpt-4",
  "targetModel": "gpt-4o",
  "platformId": null
}
```

| 字段 | 说明 |
|------|------|
| `alias` | 客户端请求的模型名（别名），必填 |
| `targetModel` | 实际调用的模型名，缺省时等于 `alias` |
| `platformId` | 限定在特定平台生效（`null` 表示所有平台），可选 |

3. 回到「数据管理」页面点击「导入」，上传修改后的 JSON 文件完成更新

::: warning
导入时 `alias` 已存在的映射会被跳过（不会更新原记录）。如需修改已有映射，请先将其 `alias` 改名或删除原记录后再导入。
:::

## 使用场景

1. **模型升级**：旧模型名映射到新模型
2. **成本优化**：将昂贵模型映射到性价比更高的模型
3. **多平台适配**：同一别名在不同平台映射到不同目标

## 通配符映射

`alias` 以 `*` 结尾时按前缀匹配：例如 `gpt-4*` 匹配所有以 `gpt-4` 开头的模型名，匹配时后缀会拼接到 `targetModel` 之后。

## 平台级模型发现

FWP 自动发现各平台支持的模型列表（定时任务默认每 6 小时），结果可在「自动模型」页面查看。发现请求走 OpenAI 兼容的 `/models` 接口：

- OpenAI 兼容平台（`openai` / `azure` / `custom`）可正常发现
- **Anthropic 类型平台暂不支持自动发现**（原生协议无 `/models` 端点），需手动添加或使用预设
