# 平台配置

## 添加平台

在管理后台的「平台管理」页面，点击「添加平台」按钮。

## 配置项

| 字段 | 说明 |
|------|------|
| 平台名称 | 自定义名称，用于标识 |
| Base URL | 平台 API 地址 |
| API Key | 平台的认证密钥 |
| 平台类型 | OpenAI 兼容 / Azure / 自定义 / Anthropic |
| 优先级 | 数值越大优先级越高 |
| 权重 | 路由分配比例 |
| RPM 限制 | 每分钟请求数限制 |
| TPM 限制 | 每分钟 Token 数限制 |

## 平台类型

平台类型决定上游协议：

- **OpenAI 兼容**：大多数厂商的 OpenAI 兼容端点（OpenAI、Google、DeepSeek 等）
- **Azure**：Azure OpenAI 服务
- **自定义**：自定义 OpenAI 兼容网关
- **Anthropic**：Anthropic 原生协议，用于官方 Claude API、GitHub Copilot 等网关

## 命名密钥

支持为每个平台配置多个命名密钥：

```json
[
  {"name": "密钥1", "key": "sk-xxx"},
  {"name": "密钥2", "key": "sk-yyy"}
]
```

## 高级设置

平台的高级设置分组中还有以下可选字段：

| 字段 | 说明 | 默认值 |
|------|------|--------|
| 透传请求头 | 需要转发给上游的下游请求头白名单（JSON 数组） | 空 |
| 注入 stream_options | 是否自动注入 `stream_options`（部分上游不支持该字段时关闭） | 开 |
| 平台白名单 | 开启后该平台收到 429 不会被封禁，仅临时降级 2 分钟（密钥错误计数自动禁用不受影响） | 关 |
| 覆盖 UA | 开启后用自定义 UA 值替换发送给上游的 User-Agent（需同时填写自定义 UA 才生效，优先级高于自定义请求头中的 UA） | 关 |
| 自定义 UA | 覆盖发送给上游的 User-Agent | 空 |
| 自定义请求头 | 发送给上游的额外请求头（JSON 对象，最多 20 条） | 空 |

> 各字段的完整说明与配置入口见「[管理后台使用说明](/guide/usage)」，平台 API 的字段定义见「[API 参考](/api/)」。

## 启用/禁用

平台支持随时启用或禁用，禁用后不会接收请求。
