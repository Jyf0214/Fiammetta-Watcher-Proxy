# 调试台与失败排查

## Playground 调试台

管理后台侧边栏「调试台」：不离开后台就能向任意模型发一条真实请求，验证平台配置是否可用。

- **模型**：下拉列出所有已启用平台发现的模型（支持搜索）
- **API Key**：选择以哪个 Key 的身份发送（默认最新活跃的 Key）
- **流式输出**：默认开启，逐字渲染并显示首字延迟、Token 用量与本次费用
- **停止**：流式过程中可随时中断

两点设计值得知道：

1. **密钥不经过浏览器**——所选 Key 的明文由服务端注入，页面上只出现 Key 名称
2. **走完整代理链路**——请求与真实业务请求完全同路径：路由、重试、限流、日志、成本记账全部生效，调试产生的用量会计入配额（审计日志中记为「调试台调用」）

::: warning 部署兼容性
调试台通过服务端回环调用本实例的 `/v1` 入口实现。个别 Serverless 平台可能禁止函数自调用 HTTP 请求，此时调试台会返回明确报错；Docker 与自托管部署不受影响。
:::
