# 出站代理

当上游平台对你所在地区或出口 IP 有限制时，可让代理请求经由 HTTP/SOCKS 出站代理转发。支持从订阅链接批量拉取代理列表、按组管理与定时健康检查。

## 入口

管理后台侧边栏「出站代理」：

- **列表页**：按组查看代理与整体健康概况
- **点击任一组**进入该组的配置详情

## 核心概念

| 概念 | 说明 |
|------|------|
| 代理组 | 一个拉取源对应一个组，组内代理来自同一订阅 |
| 组绑定 | 平台可绑定某个代理组，该平台的请求只走组内代理 |
| 默认组 | 未绑定组的平台回退使用默认组（可在设置中指定） |

## 配置项

每个组内可分别配置三类信息：

| 类别 | 内容 |
|------|------|
| 代理池 | 手动添加的代理地址，支持 `http://`、`socks4://`、`socks5://`，带凭据的地址凭据部分会脱敏显示 |
| 拉取源 | 订阅链接（返回纯文本代理列表，每行一条）；保存后立即拉取一次，并可开启定时拉取自动同步 |
| 健康检查 | 开启后按周期对组内代理发探测请求，标记不可用节点 |

## 平台绑定

在「平台管理 → 编辑平台」的设置中选择出站代理组即可。粒度支持到 **单个 API Key**：同一平台下可为个别 Key 指定不同的代理组（适合不同 Key 有不同 IP 要求的场景）。

## 定时任务

| 任务 | 行为 |
|------|------|
| 代理拉取 | 按各组的拉取周期自动同步订阅内容；移除的代理随之清理 |
| 代理健康检查 | 默认每 5 分钟一轮（仅自托管 Docker 部署且未禁用时生效） |

## 设备级禁用

自托管环境可通过环境变量 `UPSTREAM_PROXY_DISABLED` 整体关闭：

- `all` — 所有出站代理逻辑停用（请求直连上游）
- `health` — 仅停用健康检查，代理转发照常

## 使用建议

- 订阅源应返回**纯文本**代理列表（每行一条），带协议前缀；无前缀时按 HTTP 处理
- 代理数量较多时建议开启健康检查并适当延长检查周期，避免探测流量过大
- 平台与 Key 的组绑定变更即时生效，无需重启
